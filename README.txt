# 🏢 وب‌سایت گروه به‌رچاو (Bercaw Group)

> **راهکارهای هوشمند تامین و اجرای صنعت ساختمان**
> پلتفرم وب چندبخشی برای معرفی خدمات، محصولات و پروژه‌های تخصصی حوزه ساختمان و عمران.

---

## 📌 درباره پروژه

این مخزن شامل کد منبع وب‌سایت رسمی **گروه به‌رچاو** است. این وب‌سایت به صورت یک وب‌اپلیکیشن چندصفحه‌ای و ساختاریافته (Multi-Page Architecture) طراحی شده تا دسته‌بندی‌های مختلف خدمات مهندسی، تامین مصالح و تولید محتوا را در پوشه‌ها و بخش‌های مجزا به کاربران ارائه دهد.

### 🌟 حوزه‌های اصلی فعالیت

* 🧱 **آجر نما نسوز:** کاتالوگ محصولات، نمونه کارها و مشخصات فنی
* 🛗 **آسانسور و بالابر:** فرم‌های برآورد قیمت، قطعات و نمونه پروژه‌ها
* 🚪 **درب و پنجره (UPVC / آلومینیوم):** ابزارهای محاسبه و نمایش مقاطع
* 🏛️ **طراحی معماری و دکوراسیون:** نمونه کارهای نما و طراحی داخلی
* 🏗️️ **میلگرد بستر و والمش:** مشخصات فنی و اصول اجرایی مقاوم‌سازی
* 🎥 **تصویربرداری و تولید محتوا:** پوشش تصویری تخصصی و تیزرهای ساختمانی

---

## ✨ ویژگی‌های کلیدی وب‌سایت

* **طراحی کاملاً واکنش‌گرا (Responsive):** بهینه‌سازی کامل برای نمایش در موبایل، تبلت و دسکتاپ.
* **پس‌زمینه پویا (Interactive Canvas & Ambient Glows):** رندر ذرات در بخش هدر با HTML5 Canvas.
* **کارت‌های تعاملی با افکت ۳ بعدی (Tilt Effect):** انیمیشن‌های روان برای کارت‌های خدمات و ویژگی‌ها.
* **تایم‌لاین مارپیچ فرآیند کاری (S-Curve Timeline):** نمایش ۹ مرحله همکاری از مشاوره تا خدمات پس از فروش.
* **سئوی ساختاریافته (Structured Data / Schema.org):** پیکربندی JSON-LD برای شناسایی بهتر موتورهای جستجو.
* **پشتیبانی کامل از حالت راست‌چین (RTL) و فونت وزیرمتن (Vazirmatn).**

## 📂 ساختار پوشه‌ها و پروژه‌ها (Project Architecture)

```micro
bercaw-group.github.io/
├── index.html              # صفحه اصلی و هاب دسترسی‌ها
├── form.html               # فرم ثبت درخواست مشاوره و سفارش
├── assets/
│   ├── css/
│   │   └── style.css       # استایل‌های سفارشی و تایپوگرافی
│   ├── js/
│   │   └── main.js        # منطق تعاملی، انیمیشن‌ها و رندر پویا
│   └── images/             # لوگوها، آیکون‌ها و بنرها
│
├── brick/                  # بخش آجر نما نسوز
│   ├── brick-index.html
│   ├── brick-products.html
│   └── brick-portfolio.html
├── elevator/               # بخش آسانسور
│   ├── elevator-index.html
│   ├── elevator-products.html
│   ├── elevator-portfolio.html
│   └── elevator-module.html
├── window/                 # بخش درب و پنجره
├── architect/              # بخش طراحی معماری
├── wallmesh/               # بخش میلگرد بستر و والمش
├── video/                  # بخش تصویربرداری و تولید محتوا
│   ├── video-index.html
│   ├── video-products.html
│   └── video-portfolio.html
└── sitemap.xml             # نقشه سایت برای موتورهای جستجو

```

* **میزبانی:** GitHub Pages

## 🚀 راهنمای اجرا و توسعه محلی

برای اجرای پروژه روی سیستم شخصی، نیاز به نصب پیش‌نیاز پیچیده‌ای ندارید:

1. کلون کردن مخزن:
```bash
git clone https://github.com/bercaw-group/bercaw-group.github.io.git

```


2. ورود به پوشه پروژه:
```bash
cd bercaw-group.github.io

```


3. اجرای فایل `index.html` مستقیماً در مرورگر یا استفاده از افزونه **Live Server** در VS Code.
